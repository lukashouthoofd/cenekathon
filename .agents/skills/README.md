# Skills

Canonical, agent-agnostic skills in the open [Agent Skills](https://agentskills.io/specification) format:
a folder `<name>/SKILL.md` with YAML frontmatter (`name` = folder name, `description` = *when* to use it)
and a markdown body. Keep each SKILL.md short (< 150 lines); put extras in sibling files.

- Claude Code reads `.claude/skills/` → generated by `scripts/sync-skills.sh` (run after adding/removing a skill).
- Codex, Gemini CLI, Copilot, Cursor read `AGENTS.md`, which points here. Tell the agent: "read `.agents/skills/<name>/SKILL.md`".
- Validate with `scripts/check-skills.sh`.

## Adding a skill
1. `mkdir .agents/skills/<kebab-name>` and write `SKILL.md` with `name`, `description`.
2. Description starts with "Use when …" — it is what triggers loading.
3. Body: When to use · Steps · Done criteria. Concrete, no fluff.
4. `scripts/sync-skills.sh && scripts/check-skills.sh`
